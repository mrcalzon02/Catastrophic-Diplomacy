# Hull-aware ship research

Raw hull size unlocks in batches: Tech 0 = Interceptor and Corvette; Tech I = Missile Corvette, Frigate and Destroyer; Tech II = Light Cruiser, Cruiser, Heavy Cruiser and Battlecruiser; Tech III = Carrier and Dreadnought. All eleven base size families are available at Tech III.

Tech IV unlocks striker, flak, torpedo and vanguard specialist chassis; Tech V unlocks EW and command variants; Tech VI unlocks repair, logistics and tender variants. The ten art-size generations still describe ship dimensions and sprite families, not sequential tech gates.

Campaign ship purchasing and per-module research stay intact. Skirmish technology caps use the same chassis eligibility; any optional hull size limit or whitelist is a separate explicit rule. No permanent campaign ship or unique identity is changed by an encounter. Fleet Beacon auto-regression remains a subsequent feature.
